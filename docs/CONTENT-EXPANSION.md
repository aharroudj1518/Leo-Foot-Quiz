# Club connections: first expansion

Six original questions were created from primary-source historical club memberships,
using UEFA's club-competition appearance record and Manchester City's Haaland profile.
The authoring script records exact source URLs. Sources were read on 9 September 2026.
This is a small curated extraction, not a running bulk scraper or a copied quiz bank.

- Authoring: `scripts/add-connections.mjs`
- Reusable content: `src/content/connection-questions.json`
- Main generator preserves this set when rebuilding the bank.
- Total development bank: 180 questions, including 14 image/badge puzzles and six club connections.

The clubs are a selection, not a complete career or current-team claim. Each puzzle
asks which of the four options represented all clubs shown. Names and memberships
are factual inputs; question wording and UI are original. Each question remains
subject to the existing independent editorial review workflow.

Next content work: expand sources and geographic/women's-football coverage, add
source-change detection and duplicate checks, and build a review queue before
automated publication. The current implementation does not claim these are complete.

Cartoon investigation: the Commons Lionel Messi art category was checked. It contains
mixed murals, photos of art, and drawings, but did not provide a consistent player
set for this app. No new player image was imported or declared cleared from that search.

The visual preview, brand emblem and club-connections changes are on the draft PR
`https://github.com/aharroudj1518/Leo-Foot-Quiz/pull/1`; the main public domain initially
remains on the recovered older revision.
