# Asset inventory for release review

Generated 12 September 2026 from every file under the mobile project's assets directory. ASSET-INVENTORY.csv records relative path, byte length and SHA-256 of the inspected file. This is a source-tree inventory, not a claim that every file ships or has permission for commercial distribution.

Existing local provenance references are included where identifiable. Empty evidence means no reference was assigned in this inventory, not that the file necessarily lacks a licence. All review statuses remain unreviewed. The question-image register remains separate and authoritative for its existing release gate.

Before release, compare this inventory with the final Expo export and native archive, account for dependency assets (including Ionicons), record which files actually ship, and reconcile each image with the question register. Review sound generation/source records, launcher variants, splash art, brand assets and any store screenshots. Verify attribution placement and applicable licence terms using original evidence. Record the actual reviewer and assessment separately; do not treat a hash or a provenance link as approval.

Cormorant's supplied OFL and Twemoji's attribution README are present in the source tree. Their presence does not by itself verify that required notices are accessible in the final shipped app. Store screenshots and remotely hosted material are outside this directory and must be added to the final release review.
